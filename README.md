# Zamora Tamminga — Portfolio

Personal portfolio site built with Next.js, Tailwind CSS, and Sanity CMS.

## Run locally

```bash
npm install
# create .env.local with NEXT_PUBLIC_SANITY_PROJECT_ID, NEXT_PUBLIC_SANITY_DATASET, etc.
npm run dev
```

Deploys to Vercel. Content is managed at `/studio`.
